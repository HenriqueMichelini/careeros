# Closed pilot runtime verification

[#292](https://github.com/HenriqueMichelini/careeros/issues/292) was exercised with synthetic identities, local loopback HTTP and disposable PostgreSQL. The [runtime procedure](../closed-pilot-runtime-local.md) and [unapproved hosted proposal](../closed-pilot-hosted-proposal.md) keep the host, database provider, region, exact HTTPS origin, costs and recovery targets open.

The package was built twice from source `852709ee10cc441918e18eb00c5d6bce2e330f55` and tree `4fa1f15ee912dfe68c79043250e9c9e973e80ed6`. Both builds used Go 1.26.4, Node 24.15.0 and npm 11.17.0 on Linux/amd64. They produced the same manifest SHA-256 `01709cb90ec7a732b8940c5bf485f00774d50d3f58921ff68953f106f19c584d`, with identical SHA-256s for all eight bundle files. Verification rejected a changed frontend file in a separate disposable copy. The actual package rehearsal passed 51 checks using disposable PostgreSQL 18.7 and the bundled binaries and frontend assets. The session fixture supplied its synthetic cookies over loopback HTTP. Browser HTTPS and Google sign-in remain separately gated. The package contains an intentionally restricted closed surface. The rollout plan requires independently available rights handling, current shared controls and verified compatibility before any later hosted cutover or rollback.

All 453 Node tests passed across 32 isolated files. TypeScript, both offline Vite builds, scoped vet and whitespace checks passed. Default vet retained the same 15 diagnostics byte for byte.

The full Go race process exited 1. It recorded 2,663 passing test and subtest events, including all 16 new closed-package events and all 37 admission IDs. It retained 24 earlier Evaluation Lab test and subtest failures and its package failure. One previously failing Lab replay test passed in this run. The full command also refused 11 account API physical restart cases because its fixture omitted the required PostgreSQL binary setting. All 11 passed in separate corrected exact-source race runs.
