# Curated general-purpose CV (#27) — local verification

The dedicated fixed `POST /api/cv/generate` contract is documented in `docs/cv-generation-contract.md`. The workflow ranks source facts, stages cited summary/supporting wording, and requires explicit replacement. The accepted CV and its choices persist in one atomic browser-local document. Profile and Application Drafts remain independent.

Verified locally:

- TypeScript `tsc --noEmit`, all frontend unit tests (`npm test`), all Go packages (`GOCACHE=/tmp/careeros-go-cache go test ./...`), production Vite build and `git diff --check` pass.
- `npm run test:cv-generation` uses controlled API responses, with no provider request or real key. English and Portuguese short mixed experience/project/education fixtures cover proposal review, deliberate replacement, summary edits, regeneration without silent overwrite, discard, reload, desktop and 390px horizontal layout, and extractable one-page A4 PDF output.
- A synthetic 19-role source puts a distinct high-impact role last. Its controlled response selects that role and a complementary project, omits duplicate routine duties, and turns a repetitive multi-sentence description into concise supported summary/description wording. The full 19-role Profile and original cited source paragraph remain intact. This tests the curation contract and application behavior, not the provider's ranking quality.
- Empty/goal-only input receives guidance. A qualification-only accepted CV contains no sample name, skills or experience. Stale edits and cancellation invalidate responses. Controlled timeout, invalid-output, rate-limit and outage paths preserve valid content. Failed primary storage writes preserve the previous CV and reviewable proposal; failed legacy mirror writes cannot restore old choices after reload.
- Numeric, explicit negation, qualification/proficiency/seniority guard tests reject concrete unsupported alterations. Protected metadata cannot be rewritten through supporting wording. Exact outbound fields and exclusions are tested; browser request entry groups are anonymous and no contact, goal, salary/status, additional-info, credential ID or URL fields enter the request.
- `npm run test:cv-preview` passes for shared CV/Application Draft paper order. `npm run test:cv-pdf` passes English, Portuguese and empty fixtures at 12/14/16px: one A4 page, selectable ordered text, professional-link annotations, sample-free exports. The Portuguese 390px page was also inspected; controls wrap and the preview scales within the viewport.
