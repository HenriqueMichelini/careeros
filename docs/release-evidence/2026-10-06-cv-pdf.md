# One-page CV PDF verification — 2026-10-06

Local browser verification of Ticket 05 with Google Chrome 154 and Poppler 26.

- `npm run test:cv-pdf` generated English, Portuguese, and empty-Profile PDFs from the live React CV page. `pdfinfo` found one A4 page for each. `pdftotext -raw` found the selected facts and section headings in document order in both languages; the empty Profile PDF contained no preview sample text. `pdfinfo -url` found active professional-link annotations.
- The same check clicked Export A4 PDF for both filled fixtures and observed the print call. A deliberately overlong summary produced the overflow alert and did not call print.
- I rendered both filled PDFs with `pdftoppm -f 1 -singlefile -scale-to 1200 -png` and inspected the full pages. Headings, body text, and links were legible; the content sat within even margins, with no overlap or clipping. The English and Portuguese pages each used one reading column.

This verifies Chrome's A4 PDF output with the page's print settings. The browser print dialog still lets a user override paper size, scale, or margins; the UI instructs them to choose Save as PDF, A4, and 100% scale.
