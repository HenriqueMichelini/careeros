# Triage labels

Local Markdown tickets record these roles in their `Status:` line.

| Role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Specified and ready to implement once blockers clear |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be implemented |

Use the local status in the right-hand column when a skill refers to a triage role.
