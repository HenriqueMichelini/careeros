# Versioned Profile Export contract

Selected scope: #287 and owner comment 6644626253, S08-D22 comment 6330937012, optional-export/deletion comment 6330893921, and post-pilot rights comment 6550859196. This interface implements only the retained Profile and its embedded Profile Provenance. It changes no retained classes, rights or deletion clocks.

`GET /api/profile/export` returns an attachment named `careeros-profile-v1.json`, media type application/json, with no-store and nosniff. Its exact envelope is `{"format":"careeros-profile-export","version":1,"profile":<complete retained Profile v2 document>}`. Profile facts, evidence, links and recorded states are exported together; there is no projection, normalization, trust inference, import, readable companion or temporary server export file/link. Unknown future envelope or Profile versions are rejected by this client. The supported opaque values inside Profile v2 are preserved; file download uses original response bytes, not parse/stringify.

The session supplies the owner. The account header only fences cookie/account switching. No caller Profile/account selector is accepted. The same authenticated router is mounted by the explicit pilot composition and its account Function alias. Account, exact session and (in pilot mode) PilotRetrieve locks/fresh time are checked before selecting the raw BYTEA and again immediately before the actual HTTP response write while those locks remain held. No operation receipt, authentication, invitation, grant or restricted financial row is included in the payload; current authority checks necessarily query their own session/pilot records. Legitimate career fields, including certification credentialId and compensation, are not redacted by keyword. Missing saved Profile is 404; unavailable authority/storage fails closed with content-free errors.

The EN/PT Profile control requests a fresh authorized file only on deliberate activation, saves no career content to browser storage, cancels/releases response resources on owner switch/unmount, reports download initiation rather than durable file-save certainty, and displays content-free failures. Unsaved editor or browser recovery bytes are excluded. Export is optional and introduces no deletion prerequisite.
