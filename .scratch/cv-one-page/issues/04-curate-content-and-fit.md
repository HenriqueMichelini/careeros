# 04 — Help users curate a one-page CV

**What to build:** Let a user choose which supported Profile facts appear in the CV and edit the CV wording while seeing useful length and page-fit feedback. The full Profile remains the source of facts for future applications.

**Blocked by:** 02 — Put real identity and contact details in the CV; 03 — Put real education, certifications, and languages in the CV.

**Status:** ready-for-agent

- [ ] A user can include or exclude supported sections, entries, and experience or project bullets from the CV without deleting those facts from the Profile.
- [ ] Summary and bullet editing shows suggested lengths and live page-fit feedback. Guidance responds to actual wrapping and page height, rather than treating a character count as proof that the document fits.
- [ ] The default remains one A4 page. When content exceeds it, the user sees what needs attention and can revise or deselect content; the application does not silently truncate, invent, or rewrite facts.
- [ ] CV-specific choices and wording remain available after navigation and reload in the browser, independently of the full Profile, and legacy saved data still loads safely.
- [ ] Verify a short CV, a content-heavy CV, and English/Portuguese layouts at desktop and narrow viewport sizes. No AI call is needed to use these controls.
