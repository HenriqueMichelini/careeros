# 03 — Put real education, certifications, and languages in the CV

**What to build:** Let a user maintain education, certifications, and language proficiency as distinct Profile facts and show them in the CV instead of fixed sample qualifications.

**Blocked by:** 01 — Make the CV preview an honest one-page document.

**Status:** ready-for-agent

- [ ] A user can manually add, edit, and remove education entries, certifications, and languages, including the identifying details needed for a useful CV entry.
- [ ] The CV presents those facts in clear, single-column sections and omits empty sections or labels preview-only examples clearly.
- [ ] Older browser-saved Profiles and free-text additional information remain intact. No existing free-text fact is silently reclassified, deleted, or presented as a verified structured qualification.
- [ ] Profile Review, Quick Add proposals, qualification gaps, and Application Draft continue to validate and preserve the expanded Profile safely; any AI request includes only the facts needed for its workflow.
- [ ] English and Portuguese labels work without rewriting user-authored content. Verify populated, empty, and legacy Profile cases on desktop and a narrow viewport.
