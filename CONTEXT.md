# CareerOS

CareerOS uses a person's career information to create drafts for a specific job opportunity.

## Language

**Profile**:
The person's career goals, skills, experience, projects, employment status, compensation details, and other career information used as source material.
_Avoid_: Professional Repository, repository

**Application Draft**:
A generated set of a role summary, resume, cover letter, and application answers for one job opportunity. It has not been submitted to an employer.
_Avoid_: Generated Materials, results
