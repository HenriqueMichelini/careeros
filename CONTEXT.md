# CareerOS

CareerOS uses a person's career information to create drafts for a specific job opportunity.

## Language

**Profile**:
The person's career goals, skills, experience, projects, employment status, compensation details, and other career information used as source material.
_Avoid_: Professional Repository, repository

**Profile Proposal**:
A suggested change to a person's Profile, presented for review before the person accepts it.
_Avoid_: Saved change

**Application Draft**:
A generated set of a role summary, resume, cover letter, and application answers for one job opportunity. It has not been submitted to an employer.
_Avoid_: Generated Materials, results

**Field Submission**:
The complete professional information or job-posting text a person submits to a CareerOS field in one processing attempt.
_Avoid_: Prompt

**Job Posting**:
An employer's description of a job opportunity, including responsibilities, qualifications, and Application Requirements.
_Avoid_: Job prompt

**Application Requirements**:
The employer's expectations for what an applicant supplies when applying, such as salary expectations, a portfolio, or descriptions of relevant experience.
_Avoid_: Instructions to CareerOS

**Clarification Request**:
A request for missing career or job information needed to understand a Field Submission.
_Avoid_: Rephrasing Request

**Rephrasing Request**:
A request to rewrite a Field Submission whose wording could be an instruction attack, when the available evidence is insufficient to establish an actual attempt.
_Avoid_: Confirmed attack, terms violation
